STANDBY — マイク停止中

VOICE ENGINE

ヘッドホンを使用し、モニター音量を低くしてから開始してください。スピーカーではハウリングが起こることがあります。

HOW TO USE

1. START MICROPHONEを押してマイクを許可。

2. 小さな声で話し、入力レベルが動くか確認。

3. モニターをONにし、音量を少しずつ調整。

4. 増幅と均一化を調整して、聞き取りやすい設定を探します。

このページは音声を録音・保存・送信しません。加工音声を通話相手へ送る機能もありません。
